# ☁️ AWS Deployment Guide (`therahulpatil.in`)

This document provides step-by-step instructions for deploying the **Rahul Patil Hacker Portfolio** to **Amazon Web Services (AWS)** using **AWS S3 + CloudFront CDN + ACM SSL Certificate + Route 53 DNS**.

---

## 🏗️ Recommended Architecture: AWS Serverless Static Web Hosting

```
+-------------------+      +-------------------+      +---------------------+      +---------------------+
|  User Visitor     | ---> | Route 53 (DNS)    | ---> | CloudFront (CDN)    | ---> | S3 Private Bucket   |
| therahulpatil.in  |      | Custom Domain     |      | SSL Certificate     |      | HTML/CSS/JS Assets  |
+-------------------+      +-------------------+      +---------------------+      +---------------------+
```

### Why this architecture?
1. **Ultra Fast**: CloudFront distributes content across 400+ edge locations worldwide.
2. **Zero Maintenance**: No servers to patch, upgrade, or manage.
3. **Free SSL/TLS**: Free auto-renewing SSL certificate from AWS Certificate Manager (ACM).
4. **Lowest Cost**: Essentially **$0.00 to $0.50/month** (Free Tier covers 1TB data transfer & 10,000,000 requests/month).

## 🛠️ Step-by-Step Deployment Instructions

### Method 1: Infrastructure as Code (Terraform) - Recommended 🚀

#### Prerequisites:
1. Installed **AWS CLI** configured with credentials (`aws configure`).
2. Installed **Terraform** (`terraform -v`).
3. Domain `therahulpatil.in` registered in AWS Route 53 (or pointing to Route 53 Name Servers).

#### Execution:
```bash
# Navigate to aws/terraform directory
cd aws/terraform

# Initialize Terraform providers
terraform init

# Review execution plan
terraform plan

# Apply infrastructure creation on AWS
terraform apply -auto-approve
```

---

### Method 2: Manual AWS Console Setup (5 Minutes) 🖐️

If you prefer doing it step-by-step via the AWS Management Console:

#### Step 1: Create S3 Bucket
1. Open **AWS S3 Console** -> Click **Create bucket**.
2. **Bucket name**: `therahulpatil-portfolio-static` (or any unique name).
3. **Region**: `ap-south-1` (Mumbai) or your choice.
4. Keep **Block all public access** TURNED ON (CloudFront OAC will handle access securely).
5. Click **Create bucket**.

#### Step 2: Request SSL Certificate in AWS ACM
1. Open **AWS Certificate Manager (ACM)** in **`us-east-1` (N. Virginia region)** *(Note: CloudFront requires certificates in us-east-1)*.
2. Click **Request certificate** -> **Request a public certificate**.
3. **Domain name**: `therahulpatil.in` and add wildcard `*.therahulpatil.in`.
4. Select **DNS validation** -> Click **Request**.
5. In the created certificate details, click **Create records in Route 53** to auto-validate DNS ownership.

#### Step 3: Create CloudFront Distribution
1. Open **AWS CloudFront Console** -> Click **Create distribution**.
2. **Origin domain**: Select your S3 bucket `therahulpatil-portfolio-static`.
3. **Origin access**: Select **Origin access control settings (recommended)** -> Click **Create control setting**.
4. **Viewer protocol policy**: Select **Redirect HTTP to HTTPS**.
5. **Alternate domain name (CNAME)**: Add `therahulpatil.in` and `www.therahulpatil.in`.
6. **Custom SSL certificate**: Choose the certificate created in Step 2 for `therahulpatil.in`.
7. **Default root object**: Type `index.html`.
8. Click **Create distribution**.
9. Copy the S3 Bucket Policy snippet generated by CloudFront and paste it into **S3 Bucket -> Permissions -> Bucket Policy**.

#### Step 4: Configure Route 53 Domain DNS
1. Open **Route 53 Console** -> Select Hosted Zone `therahulpatil.in`.
2. Click **Create record**:
   - **Record name**: Blank (Apex domain `therahulpatil.in`)
   - **Record type**: `A`
   - **Alias**: Enable toggle -> Route traffic to **Alias to CloudFront distribution** -> Select your distribution.
3. Click **Create record** again for `www.therahulpatil.in`.

## ⚡ Syncing Local Files to AWS S3

Whenever you update your code locally, deploy updates instantly using PowerShell:

```powershell
.\aws\deploy.ps1 -BucketName "therahulpatil-portfolio-static" -CloudFrontDistId "YOUR_CLOUDFRONT_DISTRIBUTION_ID"
```

Or using AWS CLI directly:

```bash
# Sync files to S3
aws s3 sync . s3://therahulpatil-portfolio-static --exclude "aws/*" --exclude ".git/*"

# Invalidate CloudFront Cache
aws cloudfront create-invalidation --distribution-id YOUR_DIST_ID --paths "/*"
```

## 🐳 Optional Alternative: AWS EC2 (Docker + Nginx)

If you prefer hosting on an EC2 instance:

```bash
# 1. SSH into EC2 instance
ssh -i key.pem ubuntu@<your-ec2-ip>

# 2. Install Docker & Nginx
sudo apt update && sudo apt install -y docker.io nginx certbot python3-certbot-nginx

# 3. Clone portfolio repo & serve via Nginx
sudo rsync -av ./ /var/www/html/

# 4. Obtain SSL Certificate with Certbot
sudo certbot --nginx -d therahulpatil.in -d www.therahulpatil.in
```
